# LifeOps

**Personal Rule Execution System — 个人规则执行器**

LifeOps is designed around a simple loop: **rules → action → evidence → review**.

## Product principles
- Offline-first and local data by default.
- No account, ads, tracking, or AI API dependency.
- Rules are defined ahead of time; changes are logged and reviewed deliberately.
- Prioritize actionable clarity over gamification.
- Reuse proven solutions; avoid unnecessary complexity.

## First-stage scope
1. Today: a small action list.
2. Rules: precommitment and decision guardrails.
3. Review: weekly execution review.
4. Later: persistence, rule versioning, reminders, backup/restore, analytics.

This is an early scaffold, not a finished app.
