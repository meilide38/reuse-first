# reuse-first（拒绝重复造轮子）

一个可重复使用的 AI Skill：让 AI 在接到开发任务时，**先搜索现成方案，再动手写代码**。

## 核心指令

> 不要重复造轮子。接到开发任务后，先搜索 GitHub 和其他开源社区，寻找功能相近、成熟且可复用的项目或代码实现。
> 优先采用现成方案，不要轻易从零开发。
> 找到合适的实现后，先分析代码质量、许可证、依赖和兼容性，再进行必要的修复、优化和改造，最后集成到当前项目。
> 如果现有方案存在问题，优先维修和适配，而不是直接推倒重写。
> 只有确认没有合适的现成方案时，才考虑自主实现。
> 核心原则：能复用就复用，能修就不重写，能改就不重造。

## 使用方法

1. 将 `reuse-first/` 目录安装到你的 AI Agent 的 skills 目录（如 `~/.codebuddy/skills/`）。
2. AI 接到开发任务时会自动判断是否调用本 Skill，也可以手动触发。
3. AI 会按「搜索 → 评估 → 修复/改造 → 集成 → 测试」的流程工作。

## 设计动机

AI（和人）常常因为「自己写更方便」而放弃成熟实现，导致：

- 重复实现已有大量验证的复杂逻辑（如解析器、协议、算法）
- 新代码缺乏实战检验，暗藏 Bug 与边界问题
- 项目膨胀、维护成本上升

本 Skill 强制 AI 在从零开发之前先回答：**搜索过哪些现成方案？为什么不能直接复用？为什么不能维修？为什么必须重新开发？**
